# Packets P04+P05+P06+P08: auth core, PIN/OTP, audit, outbox write path — DONE (Cowork, 2026-06-13)

## P04 auth core
JWT access (15 min, claims: sub/username/role/station/vendor_id/device_key) + OPAQUE rotating
refresh tokens (random, sha256-hashed in auth_sessions — a leaked DB row is not a token).
Rotation with REUSE DETECTION: replaying a rotated refresh token revokes ALL the user's sessions.
401s carry details.server_time (clock-skew hint, §11.15). Error envelope en+mr on every auth error.
`require(*roles)` dependency guards routers; CurrentUser carries vendor_id for service-layer scoping.

## P05 PIN switch + vendor mock OTP
PIN switch: registered station device only + user.station must equal device.station; updates
device.last_seen_at. Vendor OTP: 6-digit, 10-min expiry, single-use; MOCK mode returns dev_code
in the response (removed when real SMS provider lands — service signature unchanged).

## P06 audit
Middleware: EVERY mutating request → one audit row (user/role/station/device/request_id/method/
path/action/response status), including FAILED requests; request bodies never stored (passwords).
audit.record() helper for service-level field diffs (before/after) inside the domain transaction.
Audit write failure never fails the request (logged instead). Schema refinement: audit_log.method/
path now NULL-able (service-level records have no HTTP context) — patched in architecture doc.
Postgres INSERT-only grant: ships with baseline migration (postgres-marked test, P03 handoff).

## P08 outbox write path
services/tx.py: `idempotent_replay(db, Model, client_ref)` (retry → original result) +
`enqueue_outbox(db, type, id, payload)` (same-transaction; payload frozen at write).
Proven by tests: commit-together, rollback-removes-both (simulated crash), duplicate client_ref
impossible at DB level, unknown record types rejected.
